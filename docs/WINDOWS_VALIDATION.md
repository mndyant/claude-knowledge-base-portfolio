READMEに掲載する6問は公開BM25 APIで対応する要約が先頭になることを確認しました。検索順位は回答の確かさを保証しません。新しい画像はこの実APIの検索結果を撮影しています。スマートフォン実機での操作は未確認です。

ローカルデモを実multilingual-e5-baseで起動し、同じ3つの質問ボタン・要約の展開・出典リンク・回答生成なしをデスクトップと390px幅のヘッドレスChromeで再確認しました。モデルは前日に初回取得した専用キャッシュを再利用しています。
