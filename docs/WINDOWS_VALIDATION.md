# Windows検証記録

## 2026年9月18日の追加確認

公開用ローカルコピーで163テストが成功。回答生成の明示指定、引用番号、クエリ長境界、Discordの429再試行終了を追加確認しました。外部モデル・HTTPはテストダブルを使用しています。画面例は自作4文書の既存実モデルデモであり、全量の検索精度を示す画像ではありません。

以下は9月11〜12日時点の記録です。新しい変更のGitHub CIは未実行です。

公開候補に対し、2026年9月11〜12日にWindowsネイティブ環境で実施しました。

| 対象 | 結果 | 範囲 |
|---|---|---|
| pytest | 156件通過 | HTTP・モデルはテストダブル、ChromaDBは独立した一時DB |
| 実モデル | 読込・埋め込み成功 | キャッシュ済みmultilingual-e5-base / CPU、自作サンプル4文書 |
| HTTP | 正常 | `/`・`/docs`・`/openapi.json`・`/health`・`/sources`は200 |
| 未同梱ページ | 404 | `/study`。画面自体がない場合のSwagger誘導はpytestで確認 |
| 検索 | 3クエリ成功 | 日本語の質問に対応する英語文書がそれぞれ先頭、answerはnull |

| 再実行 | 重複なし | デモDBは再実行後も4文書。pytestでも検証 |

使用環境：Python 3.14.3 / FastAPI 0.115.14 / ChromaDB 1.5.9 / sentence-transformers 3.4.1 / torch 2.13.0 CPU / pytest 8.4.2。
既存モデル・主要ライブラリを再利用し、テスト用の不足依存は分離した仮想環境へ追加しました。Python 3.11のクリーン環境からの全依存再インストールは今回の検証に含みません。

156件のテストで、FastAPI・ChromaDBによるPython 3.14の非推奨警告が計11件出ています。失敗はありません。依存更新時の互換性確認事項として残します。

実モデルのHTTP検証はループバック専用サーバーに対して実行し、外向きソケット接続を禁止した環境で確認しました。デモDBは `.portfolio-demo/` に限定し、既存の個人用DBを利用していません。
