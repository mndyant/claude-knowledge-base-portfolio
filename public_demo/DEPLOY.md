# 公開デモ

リポジトリのルートで `python scripts/build_public_demo.py` を実行し、生成された `.public-deploy/` を配置します。明示的に許可したコード・要約・画面のみを含み、ローカル検索のtorch・ChromaDB・モデル・DBは含みません。

FastAPI自動検出を使い、`/` と `/docs` をそれぞれ検証してください。配置先には最小の `requirements.txt` と `app.py` エントリーポイントも生成されます。

公式ページの内容に基づいて作成した独自要約をBM25で検索します。英語は公式原文の転載ではありません。日本語は固定要約であり、検索時のLLM生成ではありません。文書全文を再配布せず、結果から公式ページへ移動できます。確認日以降にAPI仕様が変更される可能性があるため、実装時は出典を確認してください。
